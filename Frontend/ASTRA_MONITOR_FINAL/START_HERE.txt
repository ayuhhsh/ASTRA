ASTRA MONITOR V32 - FINAL INTEGRATED FRONTEND
=================================================
Included: teammate V32 frontend design + existing Spring Boot REST API + STOMP WebSocket integration + actual stored heart-rate history chart + dynamic Health Status labels.

HOW TO RUN LOCALLY
1. Start MySQL and Spring Boot backend on http://localhost:8080.
2. Extract this ZIP, open the ASTRA_MONITOR_V32 folder in VS Code.
3. Open Terminal and run: python run_frontend.py
4. Open http://localhost:5500 and hard-refresh (Ctrl+Shift+R) if a previous version was cached.

VALIDATION
- GET /api/astronauts, /api/astronauts/{id}/health, /api/astronauts/{id}/risk, /api/alerts
- STOMP WebSocket ws://localhost:8080/ws subscribing /topic/health
- 4 demo portraits map to first four API astronaut IDs; they are illustrative, not real astronaut medical data.
- Real stored heart-rate history replaces unsupported raw-ECG view.
- Health Status is derived from prototype thresholds; NOT clinically validated.

TEST REQUEST (Postman)
POST http://localhost:8080/api/health-readings
{"astronautId":1,"heartRate":150,"spo2":85,"temperature":39.5,"stressLevel":9}
Expect 201, then latest reading + CRITICAL risk shown on dashboard.

NOTES

- Public hosting needs Spring Boot, MySQL, FastAPI hosted separately plus HTTPS/WSS configuration. The local run_frontend.py proxy is for LOCAL testing only.
